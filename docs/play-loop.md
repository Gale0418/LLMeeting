# 轉折靈感：玩法與驗證紀錄

## 本批目標

讓等待中的互動會議從「不知道要寫什麼」變成「我可以改變哪一件事」。保留使用者台詞、手動送出與隨時結案，不增加獎勵倒數、連續登入或自動續局。

## 互動循環

閱讀回覆 → 選一個轉折 → 修改草稿 → 手動送出補充 → 看 AI 如何回應 → 再互評、再插話或結案。

- 劇場：怪規則、替對手辯護、三句接龍。
- 群聊／總結辯論：時間限制、反例、小實驗。
- 抓內鬼互動：矛盾、邊界、最合理辯護。提示只使用公開發言，不讀取隱藏答案。
- 只在互動模式的 `waiting_for_user` 可用；忙碌、請求未完成、已結束或一般快速鬥技場均不可用。
- 同一個靈感連點不重複追加。既有草稿逐字保留，玩法按鈕不直接呼叫 Chrome 訊息或 Provider automation。

## 真實遊玩時要看什麼

觀察玩家是否能不經解說找到靈感、是否會修改提示，以及 AI 是否真的改變了回應，而不是只口頭附和。若選項造成困惑或 AI 一直不接招，先調整提示與回饋，不用更多按鈕掩蓋問題。示範時只用無敏感資訊的台詞，遵守各 AI 用量限制。
