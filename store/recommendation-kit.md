# LLMeeting 推薦文案包

適用於 0.5.0 候選版；發布前需核對商店版本與實機驗收結果。這是本地草稿，不代表已公開發布。

## 一句話

一個問題，多個 AI 觀點：在 Chrome 側欄比較回答、交叉互評，再整理共識與分歧。

## 可以直接分享的介紹

如果你常把同一題貼到不同 AI，LLMeeting 可以把這段流程集中到 Chrome 側欄。選擇你已登入的 AI，提出問題，就能在同一份紀錄比較各家回答、互評與總結。想中途加入討論可以用自由群聊，想玩人設與創作可以開劇場。LLMeeting 功能免費，但 AI 帳號、訂閱與用量限制仍各自計算；AI 同意彼此，也不代表答案一定正確。

分享時附上 [Chrome 商店頁面](https://chromewebstore.google.com/detail/llmeeting/cjombmcmgifhanenolhaeepbpnlchjdp)，並註明實際安裝版本；不能把候選版功能當成商店版已提供。

## 一場看得懂的示範

先用兩家已登入的 AI、預設快速鬥技場、一輪互評。不要一開始展示全部設定。

示範題：我每週只有五小時做個人專案。應該先做完整功能，還是先做小型原型？請比較取捨、指出風險，並提出一週內能驗證的做法。

展示三件事：各家如何回答、哪個假設受到質疑、最後有哪些共識與分歧。不預先安排結論，不承諾固定完成時間。只有真實 extension run 的截圖才能作為運作示範，需遮住個人帳號與聊天歷史。
